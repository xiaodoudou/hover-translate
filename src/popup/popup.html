How to use

Point at text, tap Ctrl.
Point at an image, tap Ctrl to read it too.
Tap Ctrl again to restore.
Select text, tap Shift twice.
 Tap Esc to restore the page.

Configuration

Text

A translation is longer than the line a page cut to one width. Enabled, the line scrolls while you point at it, unless the page left room around the box, which it takes instead; a menu row is built around its one line and has none, so it scrolls. Disabled always grows the box.

    Image

      Quick translate

      Select any text and tap the key: that text is replaced where it sits, and Esc puts it back. On the trigger key, which is the default, a press takes the selection when you are pointing at it and the block under the pointer otherwise.

      Text selected in a search box, a comment field or any other input is replaced there too, which is how you send a message out in a language you do not write. That one is an edit rather than a view: it stays translated, and the field's own undo is what takes it back. In the page, the selection is replaced as plain text, so links and bold inside it do not survive.

      Where a selection goes, by the writing system it is in; a row left as Same as above uses Translate to at the top. Script is all a short selection can be sorted by for free: it tells Chinese from Russian from English, but not French from English, nor Mandarin from Cantonese.

      Other

      Tapping twice is harder to trigger by accident. Alt is not offered: the browser answers a bare Alt by focusing its own toolbar, taking the key with it.

      While the key is held, outlines the block that releasing it would translate, so you can move off the wrong one before you let go. Where nothing is outlined, nothing would happen. The outline is painted outside the box and moves no text.

      This setting does not impact translation time.

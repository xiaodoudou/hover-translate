Hover Translate

Point at any text or image and tap a key, and it is translated where it stands. Everything here takes effect straight away, on pages that are already open.

How to use
  • Point at text and tap Ctrl.
  • Point at an image and tap Ctrl to have it read too.
  • Select text and tap Ctrl on it to replace just that much.
  • Tap Ctrl again on anything translated to put the original back, or Esc to restore the whole page at once.

Translating an element

Point at a paragraph, a heading, a menu row or an image and tap the key: the block under the pointer is translated in place, and tapping it again puts the original back.

Trigger

Tapping twice is harder to trigger by accident. Alt is not offered: the browser answers a bare Alt by focusing its own toolbar, taking the key with it.

While the key is held, outlines the block that releasing it would translate, so you can move off the wrong one before you let go. The outline is painted outside the box and moves no text.

This setting does not impact translation time. It only holds the loading gradient on screen long enough to be seen.

Where a block goes. A selection follows the list below instead, which starts from this same language.

Text

A translation is longer than the line a page cut to one width. Enabled, the line scrolls while you point at it, unless the page left room around the box, which it takes instead; a menu row is built around its one line and has none, so it scrolls. Disabled always grows the box.

    Image

    Off until asked for: reading an image the page did not serve itself needs a permission the extension does not install with, which is requested here.

      Translating a selection

      Select any text and tap the key on it, and only those words are replaced. Text selected in a search box, a comment field or any other input is replaced there too, which is how a message goes out in a language you do not write.

      Where a selection goes

      By the writing system it is in, read top to bottom. Same as above means the row above, so scripts that share a destination can be stacked under the one that names it; the top row has nothing above it and always names a language.

        Script is all a short selection can be sorted by for free: it tells Chinese from Russian from English, but not French from English, nor Mandarin from Cantonese.

        Trigger

        The trigger key is the default, and may also be chosen outright. A press on a key both use goes to whichever has something to act on: a selection where you are pointing, or in the field you are over, takes it, and everything else takes the block. So the counts can differ on one modifier, one tap for the block and two for the selection.

        In the page it is a view like any other translation, and tapping the key on it again puts the original back. The selection is replaced as plain text, so links and bold inside it do not survive. In a field it is an edit rather than a view: nothing marks it, nothing offers to undo it, and the field's own undo is the way back.
